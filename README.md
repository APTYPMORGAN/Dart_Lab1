# Анализатор оценок

Консольное приложение на языке Dart для анализа оценок студентов. Программа рассчитывает среднее значение, определяет максимальную и минимальную оценки, а также выводит общую статистику и количество отличников.

## Ответы на вопросы

### 1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?

В Dart тип переменной известен и проверяется на этапе компиляции. В Python типизация динамическая, поэтому многие ошибки, связанные с типами, обнаруживаются только во время выполнения программы.

Практическое преимущество Dart заключается в том, что компилятор может обнаружить ошибки заранее, ещё до запуска программы. Это помогает сделать код более надёжным и уменьшает количество ошибок во время выполнения.

### 2. Что означает `String?`? Чем отличается от `String`?

`String` означает, что переменная может содержать только строковое значение и не может быть `null`.

`String?` означает nullable-строку — переменная может содержать как строку, так и `null`.

Например:

```dart
String name = 'Артур';
String? city = null;
```

### 3. Зачем в Dart `final`, если в Python можно просто договориться не менять переменную?

`final` гарантирует, что переменную нельзя переназначить после первого присваивания. В Python подобного ограничения на уровне языка нет — программист должен самостоятельно следить за тем, чтобы значение не изменялось.

Использование `final` делает намерение программиста явным и позволяет компилятору контролировать попытки переназначения переменной.

### 4. Чем именованный параметр `{required String name}` отличается от позиционного? Приведите пример вызова.

Именованный параметр передаётся по имени, поэтому при вызове необходимо указать название параметра. `required` означает, что параметр является обязательным.

Пример:

```dart
void greet({required String name}) {
  print('Привет, $name!');
}

greet(name: 'Артур');
```

Позиционный параметр передаётся в определённом порядке:

```dart
void greet(String name) {
  print('Привет, $name!');
}

greet('Артур');
```

Таким образом, именованные параметры делают вызов функции более понятным, особенно если у функции несколько параметров.
